# v1 验收标准与发布门禁

版本1.0；2026-10-23；状态：验收计划，**全部待执行**。本文不是测试通过报告。范围见[00](00-v1-baseline.md)，架构[02](02-architecture.md)，模型[11](11-data-model.md)，周规则[09](09-checkin-model.md)。

## 1. 执行规则

每项需记录实现版本、测试环境、输入数据、实际结果、证据路径、执行人/日期、状态。状态只能为未执行/通过/失败/阻塞；不能用“写了代码”代替验证。正式v1下表全部必选，不得以未启用可选AI/同步为由免测它们的能力与降级路径。

测试层级：D=确定性领域测试，C=仓储/协议/适配契约测试，E=浏览器端到端，P=真机/安装/升级测试，R=内容/人工审查。业务不变量以D/C自动化覆盖，关键流程做E，平台行为必须P。文档验证不能替代任何实现层级。
