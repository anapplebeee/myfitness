# v1 架构与可靠性契约

版本：1.0；2026-10-23；状态：重构设计，未实现。范围见[00](00-v1-baseline.md)，数据模型[11](11-data-model.md)，周规则[09](09-checkin-model.md)，门禁[12](12-v1-acceptance.md)。现有demo整体可替换，本文不代表实现已符合要求。

## 1. 技术边界

- 单体前端与可选单体服务；Android Capacitor与HTTPS PWA复用业务代码。
- TypeScript、模块化构建与自动化测试为工程基线；构建器、视图库、适配库的具体版本在实现启动时记录ADR，本轮不安装或更改依赖。
- v1默认IndexedDB事务存储，Web和Android共用；真机验证持久化、升级、空间不足。若不能满足门禁，通过存储端口换原生数据库，不同时维护两套默认后端。
- 自托管服务采用Node.js + SQLite，存快照、revision、幂等结果与轮转备份，用数据库事务替代无锁临时文件；具体运行时/依赖版本在实现ADR固定。
- 不要求零依赖、双击file://、自动探测服务；不引入微服务、CRDT、多用户或插件平台。

## 2. 分层与端口

~~~text
页面 → 应用命令/只读查询 → 领域规则
            ↓ 端口
 LocalRepository / ModelProvider / PlatformServices
            ↓
 IndexedDB / 模型HTTP / Capacitor与浏览器

本地事务 → 持久化outbox → SyncService → 认证HTTP → 服务端SQLite事务
~~~

领域纯函数接收数据、时钟和ID生成器，不调用DOM/fetch/存储。应用服务负责事务、验证、命令幂等、快照及投影。视图不持有可变state引用，不直接修改实体或存储。

LocalRepository提供read、transaction、exportSnapshot。transaction返回可等待的CommitResult：committed/validationError/storageError/conflict，只有事务完成才提示已保存。失败必须反馈，不能吞异常后返回成功。

ModelProvider负责能力差异与请求；PlatformServices负责前后台、返回、常亮、文件分享。同步是独立应用服务，本地与远端不是二选一存储模式。

## 3. 本地事务、恢复与队列

业务实体、审计事实、数据集本地generation和outbox意图同事务提交。generation在本地单调增加；提交后才刷新查询。失败保持草稿/原数据，不生成虚假统计。

outbox持久化待上传最新快照的意图，允许合并中间变更，不承诺每次操作单独上传。同数据集至多一个在途请求；成功只确认该请求实际发送的generation，更晚本地写仍pending。

启动：打开数据库与迁移检查→恢复本地与草稿→显示页面→尝试同步。禁止先拿远端覆盖本地。关闭/切后台上传只尽力执行，可靠保存不依赖sendBeacon。计时保存restEndsAt，回前台重算剩余时间。

多标签页用事务保护未结束会话唯一性，广播失效通知；同步采用数据库租约与事务校验，不能只用内存锁。多设备离线产生多个活动会话按冲突处理，不丢弃事实。

## 4. 配对和初始状态

默认独立本地数据集，无账号和网络前置。用户在设置输入服务URL/token，验证协议后显式配对；禁止URL参数静默改服务。

空白远端：用户明确选择将本机数据初始化为远端。已有远端：预览打开为独立数据集或合并；两个非空数据集不能自动覆盖。v1每服务实例仅一个单人数据集，token授权该数据集。

连接失败保留配对和pending，本地继续使用；不静默改成新数据源。主动解除配对只断同步，保留本地事实。

## 5. 同步协议 apiVersion=1

业务快照使用11号的事实实体和必要内容快照，排除设备私有数据、密钥、草稿、投影和outbox。服务端验证schema、引用、数据集ID与大小，不再只检查是否JSON对象。API响应no-store，不经Service Worker缓存。

认证用Authorization: Bearer，token不写URL。协议如下：

| 方法 | 路径 | 结果 |
|---|---|---|
| GET | /api/health | ok/apiVersion；无需认证，不泄露数据集是否存在 |
| GET | /api/dataset | 认证后200快照+ETag；空为404且code=DATASET_EMPTY |
| PUT | /api/dataset | 认证、条件写、幂等键；成功200 revision+ETag |
| DELETE | /api/dataset | 认证、If-Match、幂等键；清远端主数据及服务内备份，成功204 |

首次PUT带If-None-Match:*，后续带If-Match:"revision"。缺条件428、条件失败412、非法JSON400、schema/引用错误422、超限413、认证失败401、无授权403、存储失败500/503。仅验证apiVersion并收到DATASET_EMPTY时才视为空，不将所有404当作可初始化。

Idempotency-Key为UUID。服务端同一事务校验条件、保存旧版备份、写新快照/revision/幂等结果。同键同请求重试返回原结果，同键异内容409。幂等记录保留7天；超期先读远端并核对快照哈希或进入冲突，不盲重试旧请求。revision是服务端不透明版本，与实体revision、本地generation不同。

请求/响应快照默认上限32MiB；客户端预检，超限保持本地并提示处理，不裁剪历史。服务端可配置，上限在认证GET响应metadata中公布。三年数据集大小必须实测通过。

### 5.1 冲突

最后成功同步的共同基线保存在本机。412时获取远端，将基线、本地、远端持久化为ConflictCopy，暂停上传但允许本地继续记。

- 按实体ID和完整规范化内容三方比对，tombstone参与比较；一边未改变时可取另一边，不同实体独立修改可合并。
- 同实体双改、删改冲突、同日不同体重、同周不同目标、多个活动会话、引用/唯一匹配冲突必须预览处理，不自动取时间较新者。
- 用户选本地/远端/人工更正；双方原副本保留并可导出。
- 提交选择前核对本地generation及远端revision，任一变动重新生成预览。
- 合并先本地事务保存，再以最新revision条件上传；再次冲突重复流程，不能退回无条件覆盖。

### 5.2 断网和响应丢失

单请求超时、指数退避、网络恢复/用户重试触发，保持pending。响应丢失用相同幂等键重试；若本地已写新generation，不能将新pending清掉。

已配对远端突然为空：提示远端已清空，禁止自动上传复活；重新初始化需明确选择。DELETE清主快照、历史备份及旧幂等结果，但保留本次删除幂等凭据7天；旧revision条件写必须失败。

## 6. 安全与备份

密钥与业务分离：Android采用经验证的系统安全存储适配器；Web说明本地保存和同源脚本读取风险。模型Key/同步token不进业务快照、JSON导出、上下文和日志。

服务默认127.0.0.1；首次配置生成token并给出本地获取方式，不写普通访问日志；局域网开放需显式配置并认证。远程访问使用HTTPS。静态服务只从构建公开目录允许文件，数据库/备份/源码不在根目录；不列目录、未知资产404，不能用首页掩盖缺失脚本。

默认同源，无通配CORS；Capacitor来源在显式允许列表中，仍需token。敏感正文不进入普通诊断日志。

保留最近10个不同成功写入前版本；备份与当前写入同事务，备份失败则本次失败。备份恢复通过完整导入校验与预览，产生新revision，不直接替换运行中的数据库文件。

清本机：确认→暂停配对→删除本地业务、队列、冲突、草稿、密钥；不删除远端，提示重新配对可能重新下载。清远端：独立明确确认，删除主数据和服务内备份；离线设备不能自动复活。外部用户复制的备份不在应用可删除范围，界面说明。

## 7. 迁移与保留

新schemaVersion=1与demo v:1无关。升级前自动备份，逐版迁移，失败保持旧库/只读诊断；未知未来版本拒绝写，不能重置为空。demo显式导入规则在11，旧localStorage key不覆盖。

事实、审计与tombstone默认长期保留；投影可重建；聊天按11策略。取消90/180天自动删事实。快照增长依三年测试评估，不沿用旧20–120KB承诺。

## 8. PWA与Android

PWA在HTTPS或支持的本机开发上下文运行，完成外壳预缓存后才承诺离线冷启动；手机普通局域网HTTP不承诺PWA安装/离线。API/模型/密钥不缓存。构建版本完整预缓存失败则不激活，训练/草稿期间不强刷更新。

Android包内资源离线可开，不注册Web Service Worker；原生目录需维护，www/dist为产物。包名、签名和数据库命名空间稳定，升级后保留数据；回滚旧应用遇未来schema拒绝写。平台门禁见04/12。

## 9. AI与诊断

AI只提供草稿/解释，应用层做schema、范围、单位、器械/过敏约束与版本校验；采纳才形成命令。JSON格式不代表业务有效。默认请求超时60秒、可取消、同操作去重，不自动循环重试付费调用；失败保留输入。

外发前展示端点和上下文范围，只传必要数据，不默认全历史。诊断记录请求ID、错误码、generation/revision，不记Key或完整健康正文。首次开启AI需确认所选第三方会收到必要资料。

本轮只定契约；按00的M0–M3实施，12的门禁全部有证据后才称正式v1。
