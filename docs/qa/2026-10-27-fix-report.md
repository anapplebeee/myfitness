## 1. 本轮修复

### 1.1 教练趋势图归一化失真（PM 深评 P0-1，最贵）

**问题**：`CoachView.vue` 柱高为 `Math.max(12, v / max(series) * 100)%`。序列最大值归一化 + 12% 下限，
导致两种双向失真：6 次同重量 → 6 根等高柱（停滞看起来像满格）；80/80.5/81 → 高低错落（1.2% 波动
看起来像大起大落）。

**改法**：

- 柱状图改为 **SVG 折线 + 面积**，Y 轴按真实 `min/max` 缩放并标注极值；
- 全程等值时 `span === 0`，折线画在垂直中线（一条水平线），如实表达"没有变化"；
- 样本不足 3 次时 `changePct = null`，界面显示「样本不足」，不再用两个点算涨幅；
- 展开详情给出**日期区间**（`9月1日 → 10月17日`）、首末值、涨跌方向；
- 折线几何抽到纯函数 `src/domain/trend.ts`，新增 `trend.test.ts` 6 项（含"6 次同重量 → 水平线"）。

**验收**：新单测覆盖「6 次同重量 → 所有点 y 相同」「上升序列后点在上方」「min/max 标注正确」。
真机实测 3 张卡各 6 点、`d` 属性正常、无 console 错误。

### 1.2 次级文字对比度（PM 深评 P0-2 / UI 评审 §4.3）

| Token | 原值 | 新值 | 实测对比度 |
|---|---|---|---|
| `--text-2` | `#5b6256` | `#4f574a` | 6.59:1 on paper |
| `--text-3` | `#8b9185` | `#656c5e` | **4.77:1** on paper / 5.44:1 on white |
| `--clay` | `#e2572c` | `#b83c18` | **4.78:1** on clay-soft |
| dark `--text-3` | `#767e6c` | `#8d9583` | **5.26:1** on card |

`--text-3` 承载日期、分组名、模板副标题等每一处辅助信息，这一改一次修掉全产品每页 9–47 处不达标。

### 1.3 训练现场减法（PM 深评 P0-4 / UI 评审 §3.5）

- **删掉独立「上次」列**：原来 44px 固定列，360px 宽时 `105 kg ×` / `6` 折成两行，且同一动作 5 行
  文字完全一样。现在上次值进入输入框 `placeholder`（清空输入时可见），行宽回到 4 列。
- **单位收进动作名右侧**：`kg/lb` 从独占整行（46px 高）改为迷你分段控件，与「要领」并排。
- **触控区补到 44px**：勾选 40 → 44，跳过 16×40 → 44×44（原来靠伪元素外扩，现在真实尺寸达标）。
- 保留了输入框预填（记录速度是这块的 8 分能力），per-set 上次值在清空后以灰字 ghost 呈现；
  动作面板头部继续显示「上次 X × Y」。

**实测**（390 / 360 两档）：组行子元素 4、行高均为 66px（不折行）、
`documentElement.scrollWidth === clientWidth`（无横向溢出）、勾选与跳过均 44×44。

### 1.4 深色按钮对比（PM 深评 P0-6 / UI 评审 §1）

- **主按钮**：深色下 `--surface-ink #1a1e16` 与页面 `#0d0f0c` 仅 1.14:1，按钮像"一行浮着的绿字"。
  深色主题反相为 **lime 底 + 墨字**（实测 15.23:1）。
- **深色 hero 次级按钮**（空白训练 / 再练一场）：8% 白底在深底上边界约 1.2:1，
  提到 **14% 底 + 28% 亮描边**，形状可辨。

### 1.5 教练页 20 张卡全展开（PM 深评 P1-8）

按练习次数排序，默认只渲染 **前 3 个**，其余收进「查看全部 N 个动作 / 收起」。
页面高度 4483 → 2303px。

### 1.6 `.label` 中文排版（UI 评审 §2.2）

`uppercase`（中文无效）、`letter-spacing: 0.14em`（把汉字拉开像水印）、
`font-weight: 620`（系统字体不保证，会回退）→ 改为 `11.5px / 0.06em / 500 / none`。

## 7. 第二轮补修（同日，P1）

### 7.1 结束面板：部分完成不做全场对比（PM 深评 P1-7 / §2.6）

**问题**：只完成 1 组时，面板拿"本次 1 组"和"上次完整 15 组"比容量，得出 `-94.2%`——
数字算得对，但比较对象错了，用户刚练完看到的是"你搞砸了"。

**改法**：

- `completion.partial` 为真时不再显示组数/容量差值，改为"本次只完成 N 个工作组，
  样本不足，先不做全场对比"；
- 分母标注为「全场完成/计划」，避免被读成"这个动作要做 17 组"；
- 部分完成只剩一条警示红（完成度说明），负向差值不再出现。

**验收**：真机走查 1/17 组结束 → `.cmp--part` 存在、页面文本无 `-xx%`。

### 7.2 饮食：日期切换（PM 深评 P1-9 / §3.7）

**问题**：写死 `businessDate()`，只能记今天；"昨晚忘了记，第二天补不了"是最高频的真实路径。

**改法**：

- `selectedDate` 状态 + 日期切换条（前一天 / 回到今天 / 后一天）；
- 摄入汇总、餐次列表、添加食物全部按 `selectedDate`，补记落在选中的那天；
- 不允许翻到未来（后一天在今天时禁用）。

**验收**：实测标题「今天吃了什么」→ 点前一天变「10月26日吃了什么」，出现「回到今天」。

### 7.3 我的：BMI 刻度与体重折叠（PM 深评 P1-14 / §2.9）

- BMI 不再是裸数字：按中国成人标准（WS/T 428-2013）给分区、距正常区间多远，
  并用四段刻度条 + 位置点呈现；
- 体重记录默认 7 条，其余收进「查看全部 N 条」。

**验收**：实测 BMI 25.2 →「超重 · 距正常上限 1.2」+ 刻度点；体重列表 7 行 + 「查看全部 14 条」。

### 7.4 训练页模板工具按钮（PM 深评 P1-12）

**问题**：`.tpl__tool` 完全没有样式，`<button>` 取浏览器默认，实测只有 22px 高。

**改法**：补 44px 最小触控区 + 描边按钮样式；选中模板卡为深色底，描边与文字反相。

**验收**：实测「编辑 / 复制」均为 52×44。
