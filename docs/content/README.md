# 内容清单 v1

版本：1.0；日期：2026-10-24；状态：**内容审核基线**
权威范围见 [00](../00-v1-baseline.md)，数据模型见 [11](../11-data-model.md)。本文回答"v1 到底要交付哪些内容、每个内容由谁审、依据是什么"，不定义产品范围。

## 1. 为什么需要这份清单

00:74 与 12:25 要求 M1 前必须有可交付内容清单。没有清单会导致三个具体问题：

- **模板缺数据**：界面有 3 套模板但动作组次未经审核，用户照练可能受伤。
- **食物缺许可**：营养数据来源不明，无法说明合法性，也无法标注置信度。
- **过滤不可实现**：没有过敏原标注，07:32 要求的"确定性过滤"没有输入。

因此本清单是 G0 的出口条件之一。

### 3.2 每个动作必须有的字段

| 字段 | 必填 | 说明 |
|---|---|---|
| name | 是 | 中文通用名，不用品牌名 |
| group | 是 | 8 个肌群之一 |
| equipment | 是 | 用于器械条件过滤 |
| mode | 是 | v1 以 load_reps 为主 |
| load | 是 | 负荷约定，决定容量能否计算 |
| cues | 是 | 2–3 条安全要领，**不得**写治疗效果 |
| alternatives | 建议 | 无器械时的替代 |

### 3.3 审核要点

- 不出现"矫正""治疗""康复"等医疗宣称。
- 不推荐憋气、极限负重等高风险做法。
- 深蹲/硬拉类必须写明脊柱中立与核心收紧。
- 替代动作需负荷可比，不能拿自重替代大重量杠铃却不提示。

## 4. 训练模板

| 模板 | 天数 | 适用 | 审核要点 |
|---|---|---|---|
| 全身基础 | 2 | 刚开始规律训练 | 每次覆盖全身，组间休息充分 |
| 全身进阶 | 3 | 有基础 | 推拉腿交替，避免连续同肌群 |
| 上下肢四分化 | 4 | 有训练习惯 | 主项 5–8 次区间，辅助 8–15 |

每个模板必须包含：`days[]`（周几、动作、组数、次数区间、休息秒、最小增量）、`progressionPolicy`（达标条件、失败保持条件、规则版本）。渐进规则不能只写自由文本。

### 5.2 数据要求

| 字段 | 要求 |
|---|---|
| kcal / protein / carb / fat | 每 100g 可食部；蛋白质记为 decigram 整数，避免浮点累计误差 |
| portion | 至少一个常用份量（如"一碗 200g"），且份量与克数一致 |
| dataVersion | 数据包版本，用户记录引用版本而非最新值 |
| sourceRef | 数据来源标识，用于许可与置信度说明 |

### 5.3 明确不做

- 不提供疾病治疗性饮食建议。
- 不对"某种食物能否吃"给绝对结论。
- 不承诺营养值精确，界面必须标注为参考值。

## 6. 过敏原标注（缺口，M1 阻断项）

当前食物库**没有任何过敏原字段**，导致 07:32 的确定性过滤不可实现。补齐要求：

| 项 | 要求 |
|---|---|
| 覆盖范围 | v1 至少标注 8 类常见过敏原：麸质、蛋、奶、大豆、花生、坚果、鱼、甲壳类 |
| 三态 | contains / mayContain / free，不允许只有布尔值 |
| 粒度 | 菜品层必须标注，不能只标配料层 |
| 未标注处理 | 视为 mayContain，宁可少推荐 |
| 审核 | 每类过敏原标注需内容审核签字，抽样复核 ≥20% |

**这是 M1 的阻断项**：未完成前，自动餐单与"过滤过敏原"相关 AC 不得标记通过。

## 7. 营养策略参数（待补）

需交付一份可审核的参数表，至少包含：活动系数表、每公斤体重蛋白推荐、目标方向调整、热量下限、最小脂肪比例、取整规则。每条参数需注明来源与适用人群，并声明不适用于孕妇、未成年人、肾病患者等特殊人群。

## 8. 版本与变更

- 内容包带 `packageId, version, checksum`；用户记录引用版本。
- 内容更新不追溯改写已记录的营养或动作（11:45）。
- 每次内容变更记入变更日志，注明审核人、日期、影响范围。
