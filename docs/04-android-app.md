# v1 Android与PWA交付设计

版本1.0；2026-10-23；待实现与真机验证。范围见[00](00-v1-baseline.md)，技术契约见[02](02-architecture.md)。现有android工程仅为demo参考，存在目录不代表APK可发布。

## 1. 交付形态

Android优先，采用Capacitor复用Web业务；PWA通过HTTPS交付。iOS上架、小程序、手表、BLE与健康平台不在v1。具体Capacitor/SDK/JDK版本、最低系统版本和依赖锁定在实现启动ADR，不能依据旧文档的环境检查判断当前机器。

源码模块、原生工程和构建配置需版本管理；dist/www是产物。android目录中的包名、签名、权限和生命周期适配不是可任意覆盖的生成物。

## 2. 原生行为

- 后台/锁屏前已提交的记录可恢复；系统杀进程后显示继续训练。
- 休息计时以持久化结束时间戳重算；不承诺后台准点通知，v1不申请通知权限。
- 常亮是用户可关闭的训练偏好，平台不支持时有明确回退；不因失败阻止记录。
- 系统返回先关弹层，再退出子页；活动训练离开后保留继续入口，不禁止切tab，不误结束。
- 文件导出使用平台可用的保存/分享路径；导入使用系统文件选择，取消不改变数据。
- 模型Key与同步token存系统安全存储；网络仅允许显式服务配置。v1不申请相机、麦克风、蓝牙和健康数据权限。
- 输入键盘不遮挡组录入确认；大字体可滚动、操作可达。

## 3. PWA与升级

HTTPS完成安装和全量外壳缓存后飞行模式冷启动；普通局域网IP的HTTP不承诺PWA离线。Capacitor包内资源不注册SW。新版资源未完整下载时不切换，活动训练和未提交草稿期间提示稍后更新。

应用升级需保持包名、签名和数据库命名空间，迁移失败保持旧数据并可恢复；旧版本遇未来schema不能写。备份在升级前完成并可导出。

## 4. 发布材料与证据

构建需记录源码提交/版本、工具链版本、依赖锁、构建命令、签名证书指纹、安装包校验和。签名私钥和token不入仓库。隐私说明覆盖本地存储、模型外发、自托管、删除/备份范围。

正式v1至少验证两台不同厂商Android真机（支持范围下界和当前常见系统）、Android Chrome PWA与桌面Chromium；具体设备型号/版本记录到12号验收结果表。全部必测功能不得仅用模拟器通过替代。上架资质和商店条款在实际上架前另行核验，本轮不作已合规承诺。

验收：AC-P01–P07及数据/同步相关真机场景。无APK安装、升级和恢复证据时只能标试用工程，不能称正式Android版。
