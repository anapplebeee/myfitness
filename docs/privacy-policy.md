# 铁馆 · 隐私政策

最后更新：2026-10-26

## 一句话

铁馆不收集你的数据。训练记录、饮食记录、体重与目标全部存在你自己的设备上。

---

## 我们收集什么

**不收集任何数据。**

具体来说：

| 常见做法 | 铁馆的做法 |
| --- | --- |
| 注册账号、手机号、邮箱 | 不需要，应用没有登录 |
| 上传训练记录到我们的服务器 | 没有我们的服务器 |
| 行为埋点、页面浏览统计 | 没有任何统计 SDK |
| 崩溃上报 | 不外发；崩溃信息只留在系统日志 |
| 广告标识符 | 不申请该权限 |
| 通讯录、位置、相机、健康数据 | 不申请这些权限 |

应用申请的 Android 权限只有一项：`INTERNET`（用于可选的同步与你自己的 AI 服务）。

---

## 数据存在哪里

**本机存储**：训练、饮食、体重、目标、设置都存在这台设备的浏览器存储（IndexedDB，回退到 localStorage）。

卸载应用或在应用内"清空本机数据"，这些记录会被删除。删除不可撤销。

**可选的多设备同步**：如果你在设置里填入了自己的同步服务器地址，应用会把整份数据快照上传到**你指定的那个地址**。我们不知道也不需要知道那个地址是什么。同步默认关闭。

---

## AI 教练

AI 功能采用"自带密钥"（BYOK）：

- 你填写的 API Key 只存在这台设备，不进数据快照、不进导出文件、不上传
- 调用模型时，应用从你的设备**直连**你填写的那家服务端点，不经过我们
- 发送给模型的内容包括：你提问的文字，以及为了让它了解你的训练情况而附上的一部分本地数据摘要（例如近几周的训练场次、目标、体重）
- 是否发送由你每次点击"发送"决定；首次使用前会明确告知并需要你确认

如果你不希望任何数据离开设备，不配置 AI 即可，其余功能完全不受影响。

---

## 导出文件

你可以随时导出完整数据为 JSON 文件。导出动作完全在本地完成，文件保存到哪由你决定。导出文件里**不包含** AI 密钥。

---

## 第三方

应用内置了动作与食物参考数据，来源与授权在应用内"内容来源与授权"中列明（含 Unlicense 等）。这些是静态内容，不构成数据外发。

应用不集成任何第三方广告、统计或社交 SDK。

---

## 儿童

应用不面向 13 岁以下儿童，也不收集任何年龄信息。

---

## 你的权利

由于数据只在你自己的设备上，以下操作都可以直接完成，不需要向我们申请：

- **查看**：应用内随时可见全部记录
- **导出**：设置 → 导出、导入与备份
- **删除**：设置 → 清空本机数据，或直接卸载应用
- **迁移**：导出 JSON 后在新设备导入
