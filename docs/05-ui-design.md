# v1 信息架构与交互规格

版本1.0；2026-10-23；状态：需求规格，待实现。范围[00](00-v1-baseline.md)，数据[11](11-data-model.md)，周规则[09](09-checkin-model.md)，验收[12](12-v1-acceptance.md)。原20幅示意及旧规格归档；旧图不能覆盖本文规则。

## 1. 四个tab

| 页面 | 主任务与入口 |
|---|---|
| 今日 | 本周目标完成数/最低目标、原计划与调整原因；今日训练/继续会话；饮食实际摘要和完整度；记录训练/饮食快捷入口 |
| 训练 | 模板/当前计划、开始空白训练、动作库、会话历史及力量趋势 |
| 教练 | 单会话、上下文范围、模型配置/失败状态、饮食解析草稿和解释 |
| 我的 | 体重、目标与限制、周日历、数据导入导出、同步、隐私与清空 |

饮食页从今日进入，体重从我的进入；不增第五tab。v1不出现“设备/分享/付费”等无能力页面。tab记忆位置，返回按弹层→子页→tab根页处理。

## 2. 首次使用

主入口“开始记录训练”，无需先交身高体重；可选快捷设置包括经验/器械、每周次数和日期。未知伤病限制显示“未提供”，不能宣传“已排除全部风险”。

使用模板前展示适用条件/动作与可改安排；使用餐单/营养估计前按07补资料与限制。允许跳过后手工记录，取消引导不生成默认健康档案或默认热量目标。

## 3. 计划与周目标

选模板/自建→预览动作和日程→明确每周计划次数与最低目标→选择生效日期→确认。改计划预览保留已完成、取消未来、新建项目和目标变化，不改历史。

日历项目菜单：周内顺延、豁免、取消、恢复、查看关联训练。跨周说明不自动搬欠账；补录是“真实练过”的事实入口。周目标调整显示原值/新值/原因并确认。统计文案严格遵循09，不显示训练饮食混合完成率。

## 4. 训练现场

默认以组录入为主，动作要点折叠，不强制演示素材。动作显示上次可比较记录、负荷约定、计划值/实际值；预填值是草稿，只有确认该组才成为完成事实。

单次点击可确认已填好的一组；提交中防重复，成功才提示已保存并进入休息。失败保留输入、显示重试，不虚假勾选。RPE可选，热身/工作组可区分。

换动作先展示可选器械/模式，确认只影响本次；旧已完成组保持，旧未完成组转跳过；新动作不自动套用旧负荷。允许加自定义动作，无合适替代可手工选择。

暂停/继续/结束/放弃分开；结束展示已完成与未录组，未录项显式跳过确认，再选择是否计入关联周目标。放弃说明不计完成但保留事实。训练中可切tab/返回，显示持续“继续训练”入口；无额外完成打卡按钮。

保存成功后即使不访问总结页也已记录。总结展示实际组数、可比较容量、历史变化、PR；首次只显示基线。事后编辑不限24小时，修改会重算指标。

## 5. 饮食和目标

入口为手工热量/蛋白、搜索食物、最近/收藏、复制、照餐单确认、可选文字解析。草稿显示份量/来源/估算，可编辑后确认；AI失败始终保留手工入口。

当天显示已记录总量，并用“部分记录/全天已确认/未记录/确认禁食”区分；只有全天完整才能展示完整差额。增加/编辑/删除餐次后提示重新确认全天；没有自动补计划。可选碳水脂肪缺失显示未知。

目标说明来源、版本、适用范围，手工或初始公式目标均需采纳；v1不展示自适应接管、每日自动处方、油量静默学习。

## 6. 教练

未配置时说明手工路径可用；首次模型外发确认端点和数据类别。上下文详情可查看此次提供范围。回答可流式，取消/超时/余额/认证/不兼容均有可读错误；输入不丢。

提取出的记录为可编辑草稿，不能直接勾全计划、改目标或写计划。采纳前校验，过期建议提示重新生成。解释必须区分实际/估算/未记录，不把旧餐次勾选当实际摄入。

## 7. 数据与同步

本地保存和远端同步两行状态：已保存本机/保存失败；未启用同步/待同步/同步中/已同步/冲突/认证失败。pending表示快照待上传，不显示未经定义的操作条数。

配对→协议认证→预览本地/远端→初始化/打开/合并。冲突页展示双方与共同基线、可导出副本、逐项选择；本地或远端变化使预览失效。断线不重新引导为另一个空数据集。

导入先预览条数、错误、重复、单位和冲突，再合并/替换；取消无写入。清本机与清远端分别说明范围，清本机不承诺远端/外部备份已删除。

## 8. 通用状态与视觉

保留铁馆的浅色底、深色主卡、克制强调色、4倍数间距、单屏一个主要操作；旧配色token仅作参考，文字须逐项测对比。正文/小字≥4.5:1，大字≥3:1，触控区域≥44×44逻辑像素；重要信息不只靠颜色。

所有数据页覆盖首次空态、内容态、加载、失败重试；离线已缓存内容可用，不用错误页挡住本地记录。图标有可访问名称，键盘/屏幕阅读顺序合理；尊重减少动效和大字体。训练进行中不强刷更新。
