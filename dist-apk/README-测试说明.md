# 测试包说明（2026-10-26 版）

## 安装

**文件**：`tieguan-debug-20261026.apk`（4.26 MB）

| 项 | 值 |
|---|---|
| 包名 | `com.tieguan.fit` |
| 版本 | 1.0（versionCode 1） |
| minSdk | 23（Android 6.0+） |
| targetSdk | 35 |
| 签名 | Android Debug（`CN=Android Debug`） |

**安装方式**（任选）：

1. 传文件到手机，用文件管理器点击安装（需允许"安装未知应用"）
2. 数据线连接后：`adb install -r -t tieguan-debug-20261026.apk`

**覆盖安装**：如果手机上已有旧版，直接覆盖即可，数据保留。

## 这个包的特殊之处

**已开启 WebView 调试**（`webContentsDebuggingEnabled: true`）。

作用：你遇到问题时，我可以直接连上去看真实状态，不用你描述。
代价：同一 WiFi 下他人理论上也能调试这台设备上的应用——**仅限本机测试，不要外传**。

## 本轮新增的四个功能，重点测这些

### 1. 引导第四步：设目标

首次打开（或清除数据后）走引导，最后一步应看到「可选 · 定个目标」：

- [ ] 能填目标体重，填了之后「我的 → 身体」能看到进度
- [ ] 能选动作并填目标力量
- [ ] **两个都不填也能点「开始使用」**（这是设计要求，不是 bug）

### 2. 训练组表（改动最大）

进入任意训练：

- [ ] 每组左侧显示「上次」的实际重量×次数
- [ ] 右侧是方形勾选框，不是「完成」文字按钮
- [ ] 点勾选后整行变绿
- [ ] **重点**：把系统字体调到最大，看组行是否还整齐

### 3. AI 教练

「教练」标签 → 配置模型：

- [ ] 不填也能用其他功能（AI 是可选的）
- [ ] 首次保存会要求确认外发，应显示数据发到哪个域名
- [ ] Key 保存后只显示 `sk-J••••Io9S` 这样掩码

> **注意**：你自己配的那个 `127.0.0.1:7863` 端点**在手机上填了会失败**，
> 因为它不支持 CORS，且手机上的 `127.0.0.1` 指手机自己。
> 这个问题我已记录为待研究项，明天不用在这一点上花时间。

### 4. 清理缓存

「我的 → 设置」底部：

- [ ] 有「清理缓存并重新加载」
- [ ] 卡片明确写了「不会删除任何记录」
- [ ] 点完之后**训练记录仍在**（这点请务必确认）
