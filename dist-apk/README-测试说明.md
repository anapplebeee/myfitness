# 测试包说明（v1.2 · 2026-10-27）

## 安装

**文件**：`lianji-debug-20261027-v1.2.apk`（6.22 MB）

| 项 | 值 |
|---|---|
| 包名 | `app.lianji.fit` |
| 版本 | 1.2（versionCode **3**） |
| minSdk | 23（Android 6.0+） |
| targetSdk | 35 |
| 签名 | 固定密钥 `CN=TieGuan`（`android/tieguan-release.keystore`） |

**安装方式**（任选）：

1. 传文件到手机，用文件管理器点击安装（需允许"安装未知应用"）
2. 数据线连接并开启「USB 调试」后：`adb install -r -t lianji-debug-20261027-v1.2.apk`

> ⚠️ **不能直接覆盖 10-26 的 v1.1 包**。v1.1 的包名是 `com.tieguan.fit`，改名后是
> `app.lianji.fit`，Android 会把它们当成两个不同的应用：装完会出现两个图标，
> **旧数据不会跟过来**。
>
> 要保住旧数据：旧版「我的 → 数据与备份 → 导出」→ 装新版 → 导入。
> 如果希望直接覆盖升级，把 `applicationId` 改回 `com.tieguan.fit` 重新出包即可
> （签名没变，改回去就能覆盖）。
>
> 从这一版开始，versionCode 3 及以后都可用同一个包名覆盖升级。

## 这个包的特殊之处

**已开启 WebView 调试**（只在 debug 构建开启）。

作用：遇到问题时可以连上去看真实状态，不用你描述。
代价：同一 WiFi 下他人理论上也能调试这台设备上的应用——**仅限本机测试，不要外传**。

## 本轮重点测这 8 项

### 1. 每日饮水

- [ ] 今日页出现「今日饮水 0 / 2000 ml」
- [ ] 点 `+200 / +300 / +500 ml`，总量与进度条立即变化，文案变「还差 X ml」
- [ ] 我的 → 设置 → 每日目标 ml 改成 2500，回今日页目标跟着变
- [ ] 杀掉 App 重进，当天记录仍在

### 2. 提醒（训练 / 喝水）

- [ ] 我的 → 设置 → 「提醒与饮水」：训练提醒默认 19:00，喝水提醒默认 09:00–21:00 / 每 120 分钟
- [ ] 点「开启通知」→ 系统权限弹窗 → 允许，右侧显示「已允许」
- [ ] **锁屏等待**：把喝水间隔改成 60 分钟，到整点应收到通知（**App 关闭也应收到**）
- [ ] 改完时间后不应收到重复通知（旧计划会被清掉重排）
- [ ] 小米/华为需在系统设置里允许「自启动 / 后台弹出」，否则可能被省电策略清掉

### 3. 当前体重与 BMI

- [ ] 我的 → 身体：四个字段「当前体重 78.2 / BMI（按当前体重）25.2 / 身高 / 目标体重」
- [ ] BMI 下方有四段刻度条与位置点，文案「超重 · 距正常上限 1.2」
- [ ] 「当前体重」标注「按最近一次记录」，不再是只有目标体重

### 4. 教练趋势图

- [ ] 教练页「动作趋势」默认只显示 3 张卡，下面有「查看全部 N 个动作」
- [ ] 图是**折线**，不是柱状；上下有真实极值标注（如 80.0 / 75.0）
- [ ] 点开某张卡：有日期区间、首末值、涨跌方向
- [ ] 长期同重量的动作应显示为**水平线**，样本不足 3 次显示「样本不足」

### 5. 训练现场

- [ ] 一组只有 4 列：组号 / 重量 × 次数 / ✓ / ×
- [ ] 360px 宽（小屏）一组不折行，没有横向滚动
- [ ] 训练中顶部**没有**「练迹 / 日期 / 本地存储」，只有训练中标题与计时
- [ ] kg/lb 在动作名右侧，不占整行
- [ ] ✓ 与 × 都更容易点中（44×44）

### 6. 结束面板

- [ ] 只完成 1–2 组就点「结束训练」：不再出现 `-94.2%`
- [ ] 改为「本次只完成 N 个工作组，样本不足，先不做全场对比」
- [ ] 分母写明「全场完成/计划」，不会被误读成单个动作的组数
- [ ] 练完整后再结束，正常的组数/容量对比仍在

### 7. 饮食日期切换

- [ ] 饮食页顶部有日期切换条
- [ ] 点「‹」回到昨天：标题变「10月26日吃了什么」，出现「回到今天」
- [ ] 在昨天补记一条，切回今天不串数据
- [ ] 今天的「后一天」是禁用的（不能记未来）

### 8. 可读性

- [ ] 日期、分组名、副标题这些灰色小字明显比之前深，强光下也能看清
- [ ] 深色模式下主按钮是**酸橙底黑字**，不再像"一行浮着的绿字"
- [ ] 深色 hero 上的「空白训练 / 再练一场」有可见边框

## 已知限制（不是 bug）

- 自适应 TDEE 仍未实现（只有静态 BMR×系数估算）
- 网页版提醒需要页面保持打开；Android App 关闭也能提醒
- 部分厂商的省电策略会拦截后台通知，需手动允许自启动
- 月视图是只读的，改计划要在周视图做
- 真机未验证：刘海/手势区安全区、长时间训练的计时精度
