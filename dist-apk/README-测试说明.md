## 本轮改了什么（重点测这 5 条）

### 0. 这一版追加的四项

- [ ] **动作演示**：训练中动作标题右侧有「要领」→ 弹出示意图 + 要领 + 上次最佳；动作库每行右侧也有「要领」
- [ ] **目标三类**：我的 → 身体 → 目标卡，体重 / 力量 / 频率三组都在；没设的那组显示虚线「去设定」
- [ ] **月历位置**：月历从「周目标」移到「训练 → 历史」顶部，周目标页只剩周视图
- [ ] **顶部可点**：点左上「铁馆」回今日页；点右上「本地存储」进数据与备份页
### 1. 返回键 / 左滑返回

- [ ] 打开底部面板（饮食添加、周目标某天、记体重…）后按**返回键**：面板关掉，**不退出应用、也不换页面**
- [ ] 在会话详情里点某一组 → 编辑面板弹出 → 返回：只关编辑面板，详情还在
- [ ] 面板已关时按返回：回到上一个 Tab；在今日页按返回：应用退到后台（不丢数据）
- [ ] 从屏幕左/右边缘向内滑：等同于返回

> 这一条是本轮真机验证发现并修掉的：之前 Capacitor 默认不拦截返回键，
> 面板打开时按返回会把整个应用退出。

### 2. 饮食按个数

- [ ] 饮食 → 早餐「添加」→ 搜"鸡蛋"：列表右侧显示 `1个 ≈ 50g`
- [ ] 点鸡蛋 → 出现「按个 / 按克」切换，默认按个
- [ ] 点两次「+」→ 显示 `2个 ≈ 100g（1个约 50g）`，热量随之变成 143 kcal
- [ ] 记录后，早餐列表里是 `鸡蛋 2个（100g）`
- [ ] 面包（两片 70g → 1 片 35g）、牛奶（杯）、苹果（个）同样可选个数

### 3. 月度日历

- [ ] 周目标页顶部有「周 / 月」切换
- [ ] 月视图能看到整月格子：深色=完成、虚线红=漏做、蓝底=豁免、小圆点=待训练
- [ ] 上方统计：训练天数 / 次数 / 计划项 / 漏做天数
- [ ] 点某天 → 弹出当天明细 →「看这一周」跳回该周
- [ ] 与周视图对同一天的状态一致（月历说完成，点进周里也是完成）

### 4. 训练完成 ↔ 周目标联动（改动最大）

- [ ] 今日页「开始训练」→ 练完点「结束训练」：**「本次计入周目标」默认已勾选**，并已匹配今天的计划项
- [ ] 点「确认结束」→ 回今日页：标题变成「今天已经练完了」，不再显示「开始训练」
- [ ] 进周目标页：完成数 **+1**
- [ ] 训练页：今天的日卡片显示「已完成」，再点它是打开训练记录，**不会又开一场**
- [ ] 计划被顺延的日子：卡片显示「顺延至 X月X日」，点开会提示"记为加练"
- [ ] 训练记录页底部有「周目标」卡，没计入时可以补关联 / 取消

### 5. 身高与体重合并

- [ ] 我的 → 身体：一张卡里同时有 身高 / 目标体重 / BMI
- [ ] 直接改「目标体重」→ 上面的「目标 74.0 kg」和下方「目标」面板同步变化
- [ ] 设置页不再有身高输入，改为「身高 / 体重 / 目标体重 · 去「身体」页」
- [ ] 原来重复的 BMI 统计卡换成了「距目标」（正数=还要减）

## 已知限制（不是 bug）

- 月视图是**只读**的，改计划（豁免/顺延/取消）要在周视图里做
- 减重目标与当前体重差距过小时会被拒绝（产品规则）
- 示例数据不含目标，所以首次进来「目标」面板是空状态引导
- 真机未验证：刘海/手势区安全区、长时间训练的计时精度
